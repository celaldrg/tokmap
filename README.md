# tokmap

**See where your repo's tokens go before an AI agent reads it.**

Claude Code, Cursor, Codex and Aider all pay for context in tokens. `tokmap` measures a folder the way an agent would see it and shows which files and folders eat the budget, and which of them (lockfiles, minified bundles, generated code, test snapshots) are probably not worth reading at all.

- One small static binary, zero dependencies, written in Rust.
- Inside a git repository it asks git for the file list, so `.gitignore` is respected. Elsewhere it skips `node_modules`, `target`, `dist`, `.venv` and friends.
- Binary files are detected and skipped.
- `--budget` turns it into a CI check: exit code 1 when the repo no longer fits.
- `--json` for scripts and dashboards.

## Install

```sh
cargo install --git https://github.com/celaldrg/tokmap
```

Or download the Linux x86_64 binary from the [latest release](https://github.com/celaldrg/tokmap/releases/latest).

## Usage

```text
tokmap [PATH] [OPTIONS]

  -d, --depth <N>      Group by the first N path levels (default: 1)
  -n, --top <N>        Show the N heaviest entries (default: 15)
  -b, --budget <N>     Compare with a token budget; exit 1 when over it (accepts 200k, 1m)
      --json           Print JSON instead of the table
      --no-git         Walk the folder instead of asking git for the file list
```

### In CI

```yaml
- run: cargo install --git https://github.com/celaldrg/tokmap
- run: tokmap . --budget 200k
```

## How the count works

`tokmap` does not ship a tokenizer. It uses a fast heuristic shaped after how the BPE tokenizers in today's LLMs treat source code: identifiers are split into chunks of about four characters, most punctuation is a token of its own, indentation and line breaks collapse to about one token, and non-ASCII letters cost about one token each. Treat the numbers as estimates for comparing files and folders, not as an exact bill from a model provider.

## What gets flagged

| Hint | Rule |
| --- | --- |
| lockfile | `package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `Cargo.lock`, `poetry.lock`, `uv.lock`, `go.sum` and others |
| minified | `*.min.*`, `*.map`, or files whose average line is longer than 300 characters |
| generated | headers like `@generated`, `DO NOT EDIT`, `Code generated by`, plus `*.pb.go` and `*_pb2.py` |
| test snapshot | `*.snap` and `__snapshots__/` |
| very large file | more than 50,000 estimated tokens |
